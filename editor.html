Keep the model list
in your hands.

Edit this form, download the catalog update ZIP, then upload it to GitHub. No access token is requested or stored here. Only someone with repository write access can publish an update.

  1. Choose a model and edit its fields. Numbers use millimetres, litres, Hz, ohms and watts as labeled.
  2. Click Keep model changes, then Download catalog update.
  3. Click Upload to GitHub, unzip the download, drag in its three files, and commit the change. Existing file is replaced with GitHub history retained.
  4. Wait for the GitHub Pages site rebuild to finish. The form checks the data before download, and the app checks it again on import. The app’s Update supported models button loads the validated list.

For a new model, upload its SVG illustration/dimension reference into assets before enabling it. Use manufacturer drawings and measured data; do not guess missing specifications. Source photos and PDFs can be uploaded there when redistribution is permitted, or linked as original references.
